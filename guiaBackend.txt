Basicamente para voces criarem o backend vcs vão precisar de 3 arquivos principais para cada rota, que são:

1. Module
   nest generate module nomeDoModulo
2. Controller
   nest generate controller nomeDoController
3. Service
   nest generate service nomeDoService

Onde o module é o arquivo que vai conter as rotas, o controller é o arquivo que vai conter as funções que vão ser chamadas pelas rotas e o service é o arquivo que vai conter as funções que vão ser chamadas pelo controller.

Basicamente é isso, vcs criam estes 3 arquivos no terminal e vão desenvolvendo a lógico dentro de Service, recomendo utilizarem o postman ou insomnia para testarem as rotas. para testar lá é tranquilo também é só colocar o endereço da rota e o método que ela aceita, se for um post ou put vcs podem passar um json no body da requisição.
